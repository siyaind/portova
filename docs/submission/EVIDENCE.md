## Reproduction

```sh
npm ci
npm test
npm run typecheck
npm run build
node --experimental-strip-types scripts/verify-testnet.mjs
```

The verification script does not request a wallet or read environment secrets. Public RPCs can prune old state; missing events remain unverified, never successful by assumption.
